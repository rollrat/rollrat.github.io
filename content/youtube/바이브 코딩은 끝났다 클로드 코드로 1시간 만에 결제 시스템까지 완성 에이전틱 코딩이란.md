- **상세 페이지 제작 팀**: 상품 정보 입력 시 헤더·설명·FAQ·구매 유도 섹션까지 포함한 상세 페이지를 자동 제작, 이미지는 이미지 생성 AI(Imagen 3 등) 활용

- **교육 팀**: 강의 주제 입력 시 리서치·스크립트·PPT·핸드아웃 4종 산출물을 병렬 생성, 기존 하루 작업을 2시간으로 단축
- **사업 개발 팀**: 공고문과 회사 자료를 인풋으로 넣으면 정부지원사업 계획서 초안을 1시간 내 자동 작성 (기존 1~2주, 컨설팅비 500만 원 절감)

### Q&A

**Q1. Claude Code가 일반 AI 채팅(ChatGPT 등)과 다른 점은 무엇인가?**
Claude Code는 단순히 코드를 텍스트로 생성하는 것을 넘어, AI가 사용자의 컴퓨터에서 직접 파일을 생성하고 코드를 실행하는 에이전틱 환경을 제공한다. ChatGPT처럼 코드를 복사해 붙여넣을 필요 없이 AI가 스스로 작업 흐름 전체를 수행한다. 이를 통해 개발 지식이 없는 사람도 완성된 앱, 자동화 시스템, 멀티에이전트 팀을 구현할 수 있다.

**Q2. 월 30만 원(Claude Max) 구독으로 실제로 10개 팀을 모두 운영할 수 있는가?**
영상에서는 Claude Max 구독료 약 30만 원이 기본 전제이지만, 사용량에 따라 요금이 올라갈 수 있다고 본인도 인정했다. 실제로 영상 제작 기간 동안 본인의 총 사용 비용은 약 3,000달러(약 430만 원)에 달했다고 밝혔다. 따라서 가벼운 활용은 30만 원 수준에서 가능하지만, 12개 인스턴스를 풀가동하는 헤비 유저라면 실제 비용은 더 높아질 수 있다.

**Q3. AI 에이전트 시스템이 대체할 수 없는 영역은 무엇인가?**
Claude 자체 분석에 따르면 고도의 전략적 판단이 요구되는 의사결정, 법적 책임이 수반되는 업무, 개인정보 및 민감정보 처리 업무는 사람이 직접 수행해야 한다고 판단했다. 마케팅·데이터·CS 영역은 대체 가능성이 높은 반면, 법무·경영 기획·HR의 최종 판단 영역은 AI 보조 수준에 머무는 것이 적절하다. 즉 AI는 반복적·분석적 업무의 실행을 맡고, 사람은 최종 판단과 책임의 주체로 남는 구조가 권장된다.
