## CLAUDE.md 지워
> 📅 2026-02-24 | ⏱️ 17.7분 | [영상 링크](https://www.youtube.com/watch?v=c7_ANA1NiS0)

### 핵심 요약
- **논문 "Repository level context files helpful for coding agent?"** 분석: CLAUDE.md, AGENTS.md 같은 컨텍스트 파일이 AI 코딩 에이전트에게 실제로 도움이 되는지 실험적으로 검증
- **AI가 자동 생성한 컨텍스트 파일**은 아무것도 주지 않았을 때보다 작업 성공률이 평균 2% 하락하고, 추론 비용은 20% 이상 증가
- **사람이 직접 작성한 컨텍스트 파일**은 평균 19% 성공률 상승 효과가 있었음
- 컨텍스트 파일이 있으면 AI가 더 많은 도구를 호출하고, 코드를 불필요하게 넓게 탐색하며 에너지를 낭비함
- **결론: CLAUDE.md를 없애라는 게 아니라, 최소한의 필수 요구사항만 남기고 나머지는 스킬(skill)로 분리하라**

**03:04 ~ 10:00 — 논문 실험 설계 및 결과**

- 세 가지 조건에서 테스트: ① 컨텍스트 없음 ② LLM 자동 생성 컨텍스트 ③ 인간이 작성한 컨텍스트

- 인간 작성 컨텍스트: 대부분의 모델에서 성공률 상승(평균 +19%), LLM 생성보다 확실히 우수
- GPT 5.2는 컨텍스트 처리에 리즈닝 토큰 22% 추가 소비, 5.1 mini는 14% 추가 소비

**10:00 ~ 17:42 — 왜 이런 결과가 나왔는가 + 실무 가이드**

- 현재 작업과 무관한 내용(다른 폴더 구조, 테스트 코드 작성법, 금지 사항 등)이 컨텍스트에 있으면 오히려 방해
- "하지 말라"는 지시도 오히려 해당 내용을 더 의식하게 만드는 부작용
- **실무 권장**: CLAUDE.md는 매번 꼭 필요한 정보만 유지, 나머지는 스킬(skill)로 분리하여 특정 작업 시에만 트리거
- CLAUDE.md를 문서(documentation)처럼 꽉꽉 채우고 있었다면 지금이 점검할 시기
- AI가 멍청해졌다고 느끼는 이유의 99%는 사용자가 잘못 쓰고 있기 때문

### Q&A

**Q1. CLAUDE.md 파일을 아예 삭제해도 되는 건가요?**
논문의 결론은 "삭제하라"가 아닙니다. 인간이 잘 작성한 컨텍스트 파일은 평균 19%의 성공률 향상을 보였습니다. 문제는 불필요한 내용이 너무 많이 들어간 경우입니다. 최소한의 필수 요구사항만 남기고, 나머지는 스킬 시스템 등으로 분리하는 것이 핵심입니다.

**Q2. LLM이 생성한 컨텍스트 파일(slash init 등)은 왜 역효과가 나는 건가요?**
LLM이 생성하는 컨텍스트는 레포지토리에서 쉽게 파악할 수 있는 정보를 중복으로 포함하는 경우가 많습니다. 에이전트가 이미 자율적으로 탐색할 수 있는 내용을 다시 주입하면, 오히려 더 넓게 탐색하도록 유도하여 스텝과 비용이 증가합니다. 또한 현재 작업과 무관한 맥락이 섞이면서 집중도가 떨어집니다.

**Q3. 컨텍스트 파일 대신 스킬(skill)로 분리하면 어떤 장점이 있나요?**
스킬로 분리하면 특정 작업을 할 때 해당 작업에 필요한 정보만 선택적으로 주입할 수 있습니다. 예를 들어 S3 업로드 작업을 할 때는 S3 관련 스킬만 트리거하면 되고, 인증이나 테스트 관련 정보는 주입되지 않습니다. 이렇게 하면 CLAUDE.md는 가볍게 유지하면서도 작업별로 정확한 컨텍스트를 제공할 수 있습니다.
