## AI 때문에 진짜 소프트웨어 기업들이 무너지나... 누가 무너지고 누가 더 강해지는가 | OpenClaw | Claude Cowork | NanoBanana 2
> 📅 2026-03-15 | ⏱️ 5.8분 | [영상 링크](https://www.youtube.com/watch?v=StiEQQcMusY)

### 핵심 요약
- AI가 단순한 챗봇을 넘어 **권한을 가진 실행자(에이전트)**로 진화하면서, 사람보다 먼저 **SaaS 소프트웨어 산업**이 압박받고 있다.
- Claude Cowork는 "디지털 동료" 컨셉으로 업무를 끝까지 수행하는 에이전트를, OpenClaw는 로컬에서 직접 행동하는 에이전트를 선보였으나 보안 이슈도 함께 드러났다.
- **UI 중심 SaaS**(반복 클릭, 정형 업무)는 에이전트에 의해 대체 압박을 받지만, **데이터·인프라 중심 기업**(Microsoft, Salesforce 등)은 AI를 내재화하여 오히려 레버리지로 활용 가능하다.
- 금융·결제·계약 등 고위험 영역에서는 AI가 "제안"하고 사람이 "승인"하는 레벨 3 자율주행 단계에 머물러 있다.
- 에이전트 시대에는 **보안·권한 관리 산업**이 새로운 황금기를 맞이할 수 있다.

### 주요 내용

**1. AI 에이전트의 등장: Claude Cowork와 OpenClaw**
Claude Cowork는 파일 접근, 업무 분할, 작업 완수까지 가능한 "디지털 동료"로 설계되었다. OpenClaw는 더 극단적으로 로컬 실행, 메신저 연결, 사용자 계정 권한 활용이 가능하지만, 인증 설정 미흡·권한 과다 부여 등 보안 문제가 동시에 드러났다. 핵심은 AI가 "똑똑해진 것"이 아니라 "권한을 얻어 행동하기 시작한 것"이다.

**2. SaaS가 먼저 흔들리는 이유**
AI는 사람을 바로 대체하기보다, 사람이 사용하던 소프트웨어를 먼저 압박한다. SaaS의 본질은 "사람이 화면에서 클릭·입력하는 구조"인데, 에이전트는 UI를 거치지 않고 워크플로우를 직접 실행하기 때문이다. 데이터 락인(전환 비용)이라는 해자가 있지만, 에이전트가 API로 직접 접근하면 이 방어막도 약해진다.

**3. AI 권한의 단계별 진화**
- 읽기 권한 → 비서
- 쓰기 권한 → 대리인
- 결제 권한 → 직원

현재 기업 AI는 자율주행 레벨 3 수준이다. 문서 정리, 메일 분류, 보고서 생성은 이미 현실이지만, ERP 수정·결제 실행·계약 체결에서는 제동이 걸린다. AI는 확률 모델이므로 0.1%의 오류도 금융 시스템에서는 치명적이기 때문이다.

**4. 승자와 패자가 갈리는 기준**
- **강해지는 기업**: 자체 데이터가 강력하고, API 중심 구조를 갖추고, AI를 내부에 통합해 워크플로를 재설계할 수 있는 기업 (Microsoft, Salesforce 등)
- **압박받는 기업**: 반복 클릭 기반, 데이터 락인이 약하고, 자동화 가능한 정형 업무가 핵심 가치인 기업
- 결제 네트워크·은행 원장·신용 평가 모델 등 면허 산업은 대체가 아니라 "부착"이 일어난다.

**5. 보안 산업의 부상**
OpenClaw 사태가 보여주듯, 에이전트 하나당 API 키·세션 토큰·접근 권한이 필요하며 관리 대상이 기하급수적으로 늘어난다. 권한 관리·감사 로그·세션 통제 기술의 중요성이 높아지며, 에이전트 시대 보안 산업의 황금기가 올 수 있다.

### Q&A

**Q1. AI가 SaaS를 대체한다면, SaaS 기업에 투자해도 괜찮을까?**
일괄적으로 판단할 수 없다. 핵심은 해당 SaaS가 "UI 위에 있는 기업"인지 "데이터 위에 있는 기업"인지를 구분하는 것이다. 자체 데이터와 API 인프라가 탄탄한 기업(예: Salesforce, Microsoft)은 AI를 내재화하여 오히려 ARPU를 높일 수 있다. 반면 단순 반복 클릭 자동화에 의존하는 SaaS는 에이전트에 의해 기능 자체가 대체될 위험이 크다.

**Q2. AI 버블론은 맞는 것인가?**
영상은 "AI가 이미 생산성을 증명하고 있다"는 입장이다. 기존 SaaS를 대체할 수 있다는 논의 자체가 AI의 실질적 생산성을 방증한다. 다만 그 가치가 모든 기업에 동일하게 돌아가지 않기 때문에, 특정 기업의 밸류에이션이 과도할 수는 있어도 기술 자체가 버블이라고 단정하기 어렵다.

**Q3. 에이전트 시대에 개인이나 스타트업이 주목해야 할 영역은?**
보안·권한 관리 영역이 유망하다. 에이전트가 늘어날수록 API 키, 세션 토큰, 접근 권한의 관리 수요가 기하급수적으로 증가한다. 또한 AI를 활용해 기존 SaaS의 워크플로를 재설계하는 "AI-네이티브 SaaS"도 기회 영역이다. 반면 단순 UI 래퍼 수준의 서비스는 진입장벽이 낮아 경쟁이 치열해질 수 있다.
