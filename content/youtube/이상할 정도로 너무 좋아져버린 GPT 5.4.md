## 이상할 정도로 너무 좋아져버린 GPT 5.4

> 📅 2026-03-06 | ⏱️ 7.4분 | [영상 링크](https://www.youtube.com/watch?v=gnzox1NGedw)

### 핵심 요약

- GPT 5.4(Codex 5.4 Extra High)로 **싱글 프롬프트 단 한 번**에 게임, PPT, 스프레드시트를 완성 — 수정 없음
- **파워포인트 완성도** 대폭 향상: 레이아웃·텍스트 사이즈 소폭 조정만 하면 거의 완벽한 디자인 출력
- **Computer Use** 기능 강화: Gmail 읽기·이메일 발송을 자율적으로 수행 (Playwright 기반)
- **Tool News** 도입 (Anthropic 툴 캐시와 동일 개념): 툴 메타데이터만 컨텍스트에 올려 토큰 절감
- **Steerability**: 추론 도중 사용자가 방향을 바꾸면 모델이 즉시 thinking을 전환 — 코딩 작업 완성도 향상

### 주요 내용

#### 1. 싱글 프롬프트 데모들
코드팩토리 채널 운영자가 Codex 앱에서 GPT 5.4 Extra High 모드를 사용해 다음을 **한 번의 프롬프트**로 생성했다:
- **테마파크 경영 게임** — 건설 가능/불가 영역 로직이 명확하게 구현됨
- **전략(공격) 게임** — AI가 스스로 게임을 플레이
- **파워포인트 슬라이드** — 5.3 대비 레이아웃·디자인 완성도 현저히 향상
- **나스닥 일주일 차트 분석 스프레드시트** — 데이터 분석·시각화 포함

#### 2. 주요 업데이트 사항
| 항목 | 내용 |
|------|------|
| 컨텍스트 윈도우 | **100만 토큰** (200만 루머는 사실 아님) |
| 컴퓨터 Use | Playwright로 브라우저 제어, Gmail 읽기·발송 자동화 |
| Tool News | 툴 메타데이터만 보유 → 토큰 절감, 레이턴시 감소 |
| 에이전틱 툴 콜링 | 동일 작업 대비 툴 호출 횟수 대폭 감소 |
| Steerability | 추론 중 사용자 추가 지시 시 즉시 방향 전환 |
| 웹서치 속도 | 이전 대비 체감 약 2배 향상 |

#### 3. OpenClone 인수 배경
Computer Use 기능 — 브라우저/앱을 직접 조작하는 방향 — 에서 OpenClone의 기술이 투영되었다고 언급. Anthropic이 같은 방향을 먼저 선보인 것과 맥을 같이함.

#### 4. 에이전트 코딩 복귀 권유
기존에 Claude Code 등으로 넘어간 개발자들에게 GPT 5.4의 **UI 생성(PPT, 그래픽 렌더링)** 품질이 크게 향상됐으니 다시 한 번 사용해볼 것을 권장.

### Q&A

**Q1. GPT 5.4 싱글 프롬프트 생성이 실제로 수정 없이 가능한가?**
영상에서 코드팩토리 운영자는 Codex 앱의 5.4 Extra High 모드를 사용해 게임·PPT·스프레드시트를 단 한 번의 프롬프트로 생성했으며, 수정 작업을 일절 하지 않았다고 명시했다. SW 벤치마크 수치 자체는 평범하지만 실제 결과물 완성도가 수치 대비 훨씬 높다는 점이 핵심이다.

**Q2. Tool News란 무엇이고, 왜 중요한가?**
Tool News는 Anthropic이 2024년 11월에 먼저 출시한 '툴 캐시(Tool Cache)' 개념과 동일하다. 기존에는 사용 가능한 툴 목록 전체를 컨텍스트 윈도우에 적재해야 했지만, Tool News를 사용하면 툴의 메타데이터(앞부분 요약)만 보유하면 된다. 토큰 사용량과 API 호출 레이턴시가 감소해 에이전트 작업 속도가 빨라진다.

**Q3. Steerability 기능은 어떤 상황에서 가장 유용한가?**
긴 코딩 작업처럼 추론이 길어질수록 엉뚱한 방향으로 흐를 수 있다. 이때 사용자가 중간에 "A 방식이 아니라 B로 해"라고 지시하면 모델이 즉시 thinking 방향을 전환한다. 기존에는 처음부터 다시 프롬프트를 작성해야 했으나, Steerability 덕분에 작업 도중 방향 수정이 가능해 완성도를 높일 수 있다.
