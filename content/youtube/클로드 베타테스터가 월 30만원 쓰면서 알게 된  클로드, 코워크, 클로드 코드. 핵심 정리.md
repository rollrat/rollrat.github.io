## 클로드 베타테스터가 월 30만원 쓰면서 알게 된  클로드, 코워크, 클로드 코드. 핵심 정리
> 📅 2026-02-14 | ⏱️ 10.2분 | [영상 링크](https://www.youtube.com/watch?v=i8z-MT-khLc)

### 핵심 요약
- 클로드 생태계의 핵심 서비스는 세 가지로 구분된다: 클로드(전략 브레인스토밍), 코워크(로컬 실무 처리), 클로드 코드(개발·자동화 시스템 구축).
- 같은 프로젝트 내에서도 단계별로 도구를 바꿔 쓰는 것이 가장 효율적이며, MCP·스킬·에이전트 같은 확장 기능은 쓰다 보면 자연스럽게 만나게 된다.
- 코워크는 로컬 폴더를 직접 읽고, 서브 에이전트로 병렬 작업을 수행하며, 스킬(재사용 가능한 업무 매뉴얼)로 반복 워크플로우를 자동화한다.
- 클로드 코드는 코드를 직접 작성해 외부 데이터(유튜브 자동완성, 네이버 검색량 등)를 수집하고, 수집과 분석을 합쳐 하나의 서비스로 만들 수 있다.
- 에이전트 팀즈(Agent Teams)는 서브 에이전트가 결과만 보고하는 것과 달리, 독립적인 전문가들이 서로 토론하며 더 강한 결론에 도달하는 구조다.

### 주요 내용

#### 핵심 서비스 3가지 한눈에 정리 (00:00~01:12)
클로드, 코워크, 클로드 코드는 각각 다른 역할을 담당한다. 클로드는 대화 기반 전략 수립, 코워크는 로컬 컴퓨터에서 실무를 처리하는 유능한 신입사원, 클로드 코드는 개발자 한 명을 고용한 것과 같은 효과를 낸다. 나머지 MCP, 스킬, 에이전트 등은 이 세 도구를 쓰다 보면 자연스럽게 접하게 되는 확장 기능이다.

#### 클로드 — 전략 브레인스토밍 (01:13~03:15)
애플 마케터 시나리오를 예시로, 맥북 에어 런칭 캠페인 아이디어를 클로드에게 요청하면 컨셉·타겟·메시지·채널 전략까지 제시한다. 불편한 점(복붙 한계)은 크롬 확장으로 해결하며, 웹 검색 기능을 활성화하면 실시간 데이터도 가져온다. MCP(커넥터)를 통해 노션, 구글 드라이브, 슬랙 등 외부 도구와 연결해 AI가 상황에 맞는 공구를 스스로 선택할 수 있다.

#### 코워크 — 유능한 신입사원 (03:16~06:39)
코워크는 지정한 폴더를 직접 읽고 결과물을 로컬에 바로 저장한다. 경쟁사(삼성, HP, 레노버) 분석 시 서브 에이전트를 복수 생성해 병렬 처리(이어 달리기가 아닌 세 명이 동시에 달리는 방식)하고, 메인 에이전트가 결과를 종합해 전략 방향을 결정한다. 잘됐던 워크플로우는 스킬로 저장해 다음 프로젝트(예: 아이폰 런칭)에도 한마디로 동일한 품질을 재현할 수 있다.

#### 클로드 코드 — 개발자 한 명이 생긴다 (06:40~09:35)
코워크가 내부 폴더 자료를 다룬다면, 클로드 코드는 외부 데이터(유튜브 자동완성 키워드, 네이버 검색량, 인스타 해시태그 트렌드 등)를 크롤링·API·자동 수집으로 직접 가져온다. 수집과 분석을 결합해 매일 자동 브리핑 도구나 SEO 자동 분석 프로그램 같은 서비스를 만들 수 있다. 에이전트 팀즈는 독립적인 전문가들이 서로 반박하며 토론해 최종 전략을 도출하는 구조로, 리서치 보조를 쓰는 것과 전문가 회의를 여는 것의 차이에 해당한다.

#### 전략은 클로드, 실행은 코워크, 시스템은 클로드 코드 (09:36~)
세 도구의 역할을 한 줄로 정리하면: 전략 수립은 클로드, 실무 처리는 코워크, 자동화·시스템 구축은 클로드 코드. 영상 말미에는 클로드 코드 일주일 게스트 패스 3장 추첨 이벤트를 안내하며, 추첨 도구 자체도 클로드 코드로 제작해 과정을 공유할 예정임을 밝혔다.

### Q&A

**Q1. 코워크의 서브 에이전트와 클로드 코드의 에이전트 팀즈는 어떻게 다른가요?**
서브 에이전트는 반복 작업을 병렬로 처리해 각자 결과물만 메인 에이전트에게 보고하는 구조다. 반면 에이전트 팀즈는 각 에이전트가 독립적인 전문가로서 서로 직접 소통하고 반박하며 토론한다. 이 과정에서 약한 가설은 걸러지고 강한 근거만 남아 더 완성도 높은 결론에 도달한다. 영상에서는 리서치 보조에게 조사를 시키는 것과 전문가 회의를 여는 것의 차이로 비유했다.

**Q2. 코드를 전혀 모르는 사람도 클로드 코드를 쓸 수 있나요?**
클로드 코드는 사용자가 말로 요청하면 AI가 직접 코드를 작성하고 실행하는 도구이므로, 코딩 지식 없이도 데이터 수집이나 자동화 도구를 만드는 것이 가능하다. 다만 클로드 코드는 터미널 기반으로 동작하며 API 연동, 크롤링, 웹 서비스 파이프라인 등 복잡한 작업을 다루기 때문에, 비개발자는 초기 환경 설정 단계에서 어려움을 겪을 수 있다. 영상에서도 코워크(코드 한 줄 몰라도 말로 시키면 실무를 끝내오는 도구)와 클로드 코드의 진입 장벽은 다르다고 구분하고 있다.

**Q3. MCP(커넥터)는 클로드에서만 쓸 수 있나요?**
영상 내용 기준으로 MCP는 클로드 챗 인터페이스에서 커넥터라는 이름으로 소개되며, 노션·구글 드라이브·슬랙 등 외부 도구와 연결해 AI가 상황에 맞는 도구를 스스로 선택할 수 있게 해준다. MCP 자체는 Anthropic이 공개한 오픈 표준 프로토콜이므로 클로드 코드 등 다른 환경에서도 활용 가능하다. 영상에서는 클로드의 확장 기능으로 소개했지만, 세 도구 모두 MCP를 통해 외부 시스템과 연결하는 것이 가능하다.
