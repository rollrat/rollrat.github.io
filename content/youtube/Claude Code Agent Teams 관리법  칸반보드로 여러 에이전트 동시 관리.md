## Claude Code Agent Teams 관리법 | 칸반보드로 여러 에이전트 동시 관리
> 📅 2026-02-20 | ⏱️ 11.6분 | [영상 링크](https://www.youtube.com/watch?v=4bIWC7UECEE)

### 핵심 요약
- Claude Code의 실험적 기능인 Agent Teams를 활용하면 팀 리더 에이전트가 백엔드, 프론트엔드, 테스트 에이전트 등 여러 서브 에이전트를 병렬로 조율하여 개발 속도를 획기적으로 높일 수 있다.
- 다수의 에이전트가 동시에 작업할 경우 각 에이전트의 진행 상황을 한눈에 파악하기 어렵다는 문제가 있으며, 이를 해결하기 위해 TaskForce.AI라는 칸반보드 기반 PM 대시보드를 MCP로 연동하였다.
- TaskForce.AI MCP를 통해 에이전트들이 작업 시작 시 티켓을 클레임하고, 진행 중 액티비티 로그를 남기며, 완료 시 상태를 자동 업데이트하도록 강제하여 프로젝트 관리 가시성을 확보한다.
- 실습 프로젝트로 FastAPI 백엔드, Next.js + Tailwind 프론트엔드, pytest 테스트 에이전트 세 팀을 동시에 스폰하여 "오늘의 명언" 웹 앱을 5분 이내에 완성하였다.
- Agent Teams 기능 활성화는 `claude_settings.json`에 실험적 옵션(`claude_code_experimental_agent_teams`)을 추가하는 것으로 간단히 설정할 수 있다.

### 주요 내용

#### 1. Claude Code Agent Teams 개요
Claude Code의 Agent Teams는 하나의 세션 안에서 팀 리더 에이전트가 여러 서브 에이전트에게 작업을 분배하고 결과를 통합하는 실험적 기능이다. 각 서브 에이전트는 독립적인 컨텍스트 윈도우를 가지며 병렬로 작동하므로, 기존 단일 인스턴스 대비 개발 속도가 크게 향상된다.

#### 2. 다중 에이전트 관리의 문제와 TaskForce.AI 소개
에이전트 수가 늘어날수록 터미널만으로는 각자의 진행 상황을 추적하기 어렵다. 이를 해결하기 위해 채널 운영자가 직접 개발한 TaskForce.AI(칸반보드 형태의 PM 대시보드)를 MCP 서버로 연동하였다. 에이전트들은 작업 전 티켓을 등록·클레임하고, 진행 과정에서 액티비티 로그를 남기며, 완료 후 티켓 상태를 자동으로 업데이트한다.

#### 3. 프롬프트 설계 및 에이전트 스폰 과정
프롬프트에는 (1) TaskForce 칸반보드에 업무 단위 티켓을 먼저 등록할 것, (2) 역할별로 에이전트를 스폰할 것, (3) 각 에이전트는 티켓 상태를 실시간 업데이트하며 진행할 것을 명시하였다. 실제 실행 시 6개의 티켓이 자동 생성되었고, 백엔드·프론트엔드·테스트 에이전트가 각 티켓을 클레임하며 병렬 개발을 시작하였다.

#### 4. 실시간 개발 진행 및 결과
- 백엔드 에이전트: FastAPI 앱 생성, CORS 미들웨어 설정, `/quote` 엔드포인트 구현 완료. pytest 테스트 11개 전부 통과.
- 프론트엔드 에이전트: Next.js 초기 설정, 명언 카드 UI(그라데이션 배경, 로딩 스피너, 새로고침 버튼 등) 구현 완료.
- 테스트 에이전트: 7개 테스트 케이스 + 무결성 테스트 1개 포함 총 11개 테스트 전부 통과.
- 의존성 이슈로 일부 티켓 클레임 실패가 발생했으나 팀 리더 에이전트가 대신 처리하며 전체 완료.
- 전체 개발 소요 시간은 약 5분 이내.

#### 5. 설정 방법
터미널에서 `~/.claude/settings.json` 파일을 열고 `"claude_code_experimental_agent_teams": true` 옵션을 추가하면 Agent Teams 기능이 활성화된다.

### Q&A

**Q1. Agent Teams 기능을 사용하려면 어떻게 설정해야 하나요?**
Agent Teams는 현재 실험적(experimental) 기능으로, `~/.claude/settings.json` 파일에 해당 옵션을 직접 추가해야 활성화된다. 영상에서는 `nano` 편집기로 파일을 열어 `"claude_code_experimental_teams": true`와 유사한 플래그를 삽입하고 저장하는 방법을 보여준다. TaskForce.AI MCP 서버도 같은 설정 파일의 MCP 목록에 등록해야 연동이 가능하다. 설정 후 Claude Code를 재시작하면 팀 리더가 서브 에이전트를 스폰할 수 있는 상태가 된다.

**Q2. TaskForce.AI MCP가 없으면 Agent Teams를 쓸 수 없나요?**
Agent Teams 자체는 TaskForce.AI 없이도 사용할 수 있다. 다만 MCP 없이는 터미널 출력만으로 각 에이전트의 진행 상황을 추적해야 하므로, 에이전트 수가 많아질수록 관리가 매우 어려워진다. TaskForce.AI는 채널 운영자가 별도로 개발한 PM 대시보드로, 티켓 자동 생성·에이전트 자동 할당·상태 실시간 업데이트 기능을 제공하여 대형 프로젝트에서의 가시성을 크게 높여준다. 향후 강의에서 MCP 서버 구축 방법도 공개할 예정이라고 언급하였다.

**Q3. Agent Teams 사용 시 에이전트 간 충돌이나 오류는 어떻게 처리되나요?**
영상에서도 일부 티켓에서 의존성 이슈로 인해 클레임 실패가 발생하였다. 이 경우 팀 리더 에이전트가 해당 작업을 직접 처리하거나 다른 에이전트에게 재할당하는 방식으로 자동 복구가 이루어졌다. TaskForce.AI 칸반보드를 통해 어떤 티켓에서 문제가 생겼는지 즉시 확인할 수 있으므로, 사용자가 필요 시 수동으로 개입하여 의존성 이슈를 해결한 뒤 나머지 티켓을 완료 처리할 수도 있다.
