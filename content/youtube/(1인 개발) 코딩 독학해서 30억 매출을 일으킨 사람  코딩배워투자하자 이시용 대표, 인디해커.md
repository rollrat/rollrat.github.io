## (1인 개발) 코딩 독학해서 30억 매출을 일으킨 사람
> 📅 2026-02-01 | ⏱️ 약 25분 | [영상 링크](https://www.youtube.com/watch?v=ioNB91fUDP8)

### 핵심 요약
- 비전공자인 이시용 대표는 2020년 겨울, 웹 개발 지식이 거의 전무한 상태에서 독학으로 MBTI 심리 테스트 플랫폼 'K테스트'를 개발해 누적 매출 약 30억 원을 달성했다.
- 개발의 97~98%를 혼자 담당했으며, 극소수 부분에서만 외부 개발자에게 자문을 받았다. 공동 대표는 마케팅과 기획을 맡아 역할을 분담했다.
- 생활코딩(이고잉 님)의 무료 강의와 구글링, 스택 오버플로우만으로 한 달 만에 리액트 클래스 컴포넌트 기반의 서비스를 완성했다.
- 초기에는 GitHub Pages 무료 호스팅과 JSON 파일로만 운영하다가, '퍼스널 컬러 테스트'가 네이버 실시간 검색어 1위에 오르며 폭발적으로 성장했고, 이후 AWS로 이전했다.
- 수익화는 카카오 애드핏을 먼저 붙이고, 이후 구글 애드센스를 추가하는 방식으로 광고 수익 모델부터 시작했다.

### 주요 내용

**누적 매출 30억 달성, 비전공자 독학 개발자 소개 (00:00~01:04)**
이시용 대표는 컴퓨터 공학 비전공자로, 코딩배워투자하자 강의 플랫폼을 운영 중이며 2025년 12월 기존 법인 업무를 마무리하고 현재는 차기 비즈니스를 준비 중이다. 소프트웨어 사업부 기준 누적 매출 약 30억 원을 달성했다.

**30억 매출 규모의 실체 (03:00~03:49)**
30억은 법인 내 소프트웨어 사업 단일 사업부의 누적 매출 기준이다. 소프트웨어 특성상 비용이 거의 없으며, 개발의 97~98%는 본인이 직접 수행했고 나머지는 기능 구현에 필요한 자문 수준의 도움이었다.

**개발 비중 98%, 비전공자가 혼자서 서비스를 만들기까지 (03:49~05:50)**
당시 본인의 개발 역량을 70점 만점 기준 0.5점 수준으로 표현했다. 파이썬으로 데이터 분석 정도만 해봤고, 완성된 웹·앱·프로그램을 만들어본 경험은 전혀 없었다.

**2020년 웹 개발 개념조차 없던 시절 (05:50~08:28)**
공동 대표와 함께 코로나 시대 트렌드를 파악해 MBTI 심리 테스트 플랫폼 아이디어를 떠올렸다. 당시 MBTI 테스트를 하나의 플랫폼에 모아둔 서비스가 없었고, 여러 브랜드의 테스트를 한 곳에서 볼 수 있는 구조를 기획했다.

**케이테스트(K-TEST) 기획 (08:28~10:42)**
테스트 데이터 구조를 처음부터 규격화해 JSON으로 설계했다. 하나의 테스트당 썸네일 URL, 인트로 이미지, 12개 질문, 16개 결과 데이터를 JSON으로 하드코딩하는 방식으로 구현했다.

**생활코딩으로 독학 (10:42~12:34)**
2020년 11월 말부터 12월 말까지 약 한 달간 집과 스타벅스를 오가며 생활코딩 강의를 중심으로 독학했다. 에러가 나면 구글링, 스택 오버플로우에서 해결책을 찾아 적용하는 반복 과정으로 개발을 진행했다.

**리액트 클래스 컴포넌트로 시작 (12:34~16:17)**
훅(Hook)이 보편화되기 이전의 클래스형 컴포넌트로 개발했으며, 객체 지향 개념조차 모르는 상태에서 코드를 "외우듯이" 작성했다. props 전달 개념도 경험으로 체득하는 방식이었다.

**깃허브 페이지로 첫 배포 (16:17~20:45)**
백엔드 없이 프론트엔드만으로 구성된 정적 사이트를 GitHub Pages에 무료 배포했다. 데이터베이스 없이 JSON 파일을 정적 파일에 포함시켜 운영했으며, 코드 기반은 이후에도 크게 변경되지 않고 유지되었다.

**카카오 애드핏, 구글 애드센스로 수익화 (20:45~23:06)**
심사가 까다로운 구글 애드센스보다 카카오 애드핏을 먼저 붙여 광고 수익을 시작했다. 이후 구글 애드센스도 추가해 K테스트 현재까지 운영 중이다.

**네이버 실시간 검색어 1위, AWS 이전 (23:06~25:00)**
런칭 약 3개월 후 특정 테스트가 네이버 실시간 검색어 1위를 달성하며 폭발적인 트래픽이 몰렸고, GitHub Pages 한계를 넘어서며 AWS S3 + CloudFront 구조로 전환했다. 이 과정에서 외부 개발자의 배포 도움을 처음으로 받았다.

**퍼스널 컬러 테스트 대성공 (25:00~)**
터진 테스트는 '퍼스널 컬러 테스트'였으며, 트위터를 통해 바이럴이 시작되어 해외 트래픽까지 대거 유입됐다. 해외 트래픽 대응을 위해 AWS CloudFront CDN을 도입했다.

### Q&A

**Q1. 코딩을 전혀 모르는 상태에서 어떻게 한 달 만에 서비스를 만들 수 있었나요?**
이시용 대표는 이론적인 이해보다 "일단 돌아가게 만드는 것"을 목표로 잡고 시작했다. 생활코딩의 무료 리액트 강의를 보면서 코드를 마치 영어 단어를 외우듯 따라 작성했고, 에러가 발생하면 구글링과 스택 오버플로우를 통해 해결하며 전진했다. 객체 지향, 훅 등의 개념을 몰라도 "이렇게 하면 동작하더라"는 식으로 경험을 쌓아가며 한 달 안에 최소 기능의 결과물을 완성했다. 완성도보다 실행 가능성에 집중했기 때문에 가능했던 방식이다.

**Q2. 처음 수익이 발생하기까지 얼마나 걸렸고, 어떻게 수익화했나요?**
2021년 1월 런칭 후 약 2~3개월 동안 카카오 애드핏 광고를 붙여 운영하면서 여러 테스트 콘텐츠를 계속 추가했다. 그 중 '퍼스널 컬러 테스트'가 네이버 실시간 검색어 1위에 오르면서 대규모 트래픽이 유입됐고, 광고 수익이 본격적으로 발생하기 시작했다. 초기에는 결제 솔루션 연동이 기술적으로 어려웠기 때문에 광고 모델부터 시작한 것이 결과적으로 현명한 선택이었다. 이후 구글 애드센스도 추가했다.

**Q3. 백엔드나 데이터베이스 없이 서비스를 운영할 수 있었던 이유는 무엇인가요?**
K테스트는 MBTI 심리 테스트라는 특성상 사용자의 입력 데이터를 서버에 저장할 필요가 없었다. 테스트 질문과 결과 데이터를 JSON 파일로 정적 파일에 포함시켜 클라이언트 단에서만 처리했기 때문에 백엔드 없이도 동작이 가능했다. 이미지는 외부 URL을 참조하는 방식으로 처리했으며, 이 덕분에 GitHub Pages 같은 무료 정적 호스팅으로도 초기 서비스를 운영할 수 있었다. 트래픽이 폭증한 뒤에야 AWS S3 + CloudFront 구조로 전환했다.
