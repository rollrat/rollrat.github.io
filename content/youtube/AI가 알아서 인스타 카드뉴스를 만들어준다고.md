## AI가 알아서 인스타 카드뉴스를 만들어준다고?
> 📅 2026-02-21 | ⏱️ 22분 | [영상 링크](https://www.youtube.com/watch?v=55tVCT3CfNw)

### 핵심 요약
- Claude Code CLI(터미널)에서만 작동하는 팀 에이전트 기능을 활용해 인스타그램 카드뉴스를 주제 입력만으로 자동 생성할 수 있다.
- 카드뉴스 생성 파이프라인은 리서치 → 팩트 검증 → 카피 작성 → 후킹 팀 토론 → HTML 렌더링 → PNG 출력 순으로 자동화된다.
- 팀 에이전트의 핵심은 카피라이터와 후킹 전문가 에이전트가 메인 오케스트레이터를 거치지 않고 직접 토론하며 품질 기준(후킹 점수 7점 이상)을 충족할 때까지 반복 개선하는 구조다.
- HTML 템플릿을 한 번 완성해 두면 이후에는 주제와 스타일만 지정해도 동일한 퀄리티의 카드뉴스를 계속 생성할 수 있다.
- 자동화의 핵심 경쟁력은 팀 에이전트 기술 자체보다 워크플로(파이프라인) 설계에 있다.

### 주요 내용

#### 0:00 인트로 — 미리보기
Threads에 공유했던 팀 에이전트 카드뉴스 자동화 결과물에 대한 반응이 좋아, 구체적인 구현 방법을 가이드 형식으로 공개하게 됐다. 데스크톱 앱 Claude에서는 팀 에이전트가 지원되지 않으며, 반드시 Claude Code CLI(터미널)를 사용해야 한다.

#### 1:24 에이전트 팀 활성화 설정
Claude Code 공식 문서에 안내된 대로 `settings.json`에 환경 변수를 `1`로 설정해 팀 에이전트를 활성화한다. 비개발자는 Claude Code 터미널에서 "팀 에이전트를 활성화하고 싶은데 settings.json에 추가해줘"라고 요청하면 된다.

#### 2:24 카드뉴스 구조 토론 (검토 → 보완 → 승인)
팀 에이전트 파이프라인은 4단계로 구성된다. ① 리서치 및 카피 작성, ② 후킹 팀 토론(카피라이터 × 후킹 전문가 에이전트가 점수 미달 시 자동 재작성), ③ 슬라이드 흐름 구조 토론(검토·보완·승인), ④ 1080×1350 인스타그램 규격 PNG 자동 렌더링.

#### 7:00 샘플 템플릿 소개
clean, magazine, toss, premium, elegant, bold, minimal 등 7가지 스타일 템플릿을 팀 에이전트로 병렬 처리해 생성한다. 프롬프트를 붙여 넣으면 기본 프로젝트 세팅이 완료되며, 마음에 드는 템플릿을 그대로 사용하거나 커스터마이징할 수 있다.

#### 7:42 레퍼런스 디자인 참고
원하는 디자인 레퍼런스 이미지를 캡처해 Claude에 전달하고 "이 레퍼런스에 맞게 HTML 템플릿 샘플 만들어줘"라고 요청한다. 초기 결과물이 레퍼런스와 차이가 있을 수 있으므로 샘플 번호를 확인하며 반복 수정해 원하는 디자인에 근접시킨다.

#### 10:00 실제 생성 과정 데모 (리서치 → 카피 → 렌더링)
"2026 AI 트렌드, 블루프린트 스타일"을 주제로 카드뉴스 생성을 실행했다. 리서치 → 팩트 검증 → 병렬 서브 에이전트 실행(팩트체커, 보안 리서치) 순으로 진행되며, 이 단계는 병렬 서브 에이전트 처리로 팀 에이전트 토론과는 구분된다.

#### 13:15 AI 에이전트 토론 과정 (후킹 평가)
카피라이터가 작성한 카피를 후킹 전문가가 평가해 1라운드 6점을 부여하고 수정을 지시했다. 카피라이터가 수정 후 2라운드에서 8점을 달성해 합의 선언이 이뤄졌다. 최대 3라운드까지 평가하며, 기준점(7점 이상) 달성 시 자동으로 다음 단계로 넘어간다.

#### 16:33 최종 슬라이드 완성 & 수정
생성된 카드뉴스 중 텍스트 깨짐, 원형 차트(→ 막대 차트로 교체), 배경 이미지 누락 등을 추가 지시로 수정했다. 수정 시 샘플 이미지를 첨부하고 구체적 수치(예: 1.5배 확대)를 명시하면 정밀하게 반영된다.

#### 20:58 결과물 확인 & 마무리
템플릿을 한 번 완성하면 이후에는 주제와 템플릿 스타일만 입력해 반복 생성이 가능하다. 팀 에이전트의 본질은 워크플로 설계에 있으며, GitHub README에 프롬프트와 사용 방법을 공개했다.

### Q&A

**Q1. 일반 Claude 앱 사용자도 팀 에이전트로 카드뉴스를 만들 수 있나요?**
아니다. 팀 에이전트 기능은 Claude Code CLI, 즉 터미널에서 실행되는 환경에서만 작동한다. 일반 데스크톱 앱이나 웹 Claude에서는 지원되지 않는다. 따라서 Claude Code가 먼저 터미널에 설치되어 있어야 하며, 그 이후 settings.json에 팀 에이전트 활성화 설정을 추가해야 사용할 수 있다.

**Q2. 팀 에이전트 토론은 어떤 기준으로 멈추나요?**
후킹 전문가 에이전트가 카피를 평가해 7점 이상의 점수를 부여하면 합의가 선언되고 토론이 종료된다. 기준 미달 시 카피라이터가 수정을 진행하고 재평가를 받는 구조이며, 최대 3라운드까지 반복된다. 영상의 데모에서는 1라운드 6점에서 2라운드 8점으로 상향되어 2라운드 만에 종료됐다.

**Q3. 디자인 템플릿을 처음 만드는 과정이 어렵지 않나요?**
처음에는 레퍼런스 이미지와 완전히 동일하게 나오지 않기 때문에 반복적인 수정이 필요하다. 수정 시 샘플 이미지를 Claude에 전달하고 구체적인 수치나 변경 사항을 설명하면 점진적으로 원하는 디자인에 근접할 수 있다. 한 번 템플릿이 완성되면 이후에는 별도 수정 없이 주제만 바꿔 동일 스타일로 카드뉴스를 반복 생성할 수 있으므로 초기 투자 비용이 이후에 충분히 회수된다.
