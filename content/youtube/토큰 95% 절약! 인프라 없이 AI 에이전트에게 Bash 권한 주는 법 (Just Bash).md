## 토큰 95% 절약! 인프라 없이 AI 에이전트에게 Bash 권한 주는 법 (Just Bash)
> 📅 2026-02-09 | ⏱️ 7분 | [영상 링크](https://www.youtube.com/watch?v=LdMDEXbaTQM)

### 핵심 요약
- **Just Bash**는 TypeScript로 작성된 인메모리 가상 파일 시스템 기반의 시뮬레이션 Bash 환경으로, 실제 서버/컨테이너 없이도 AI 에이전트에게 Bash 실행 권한을 부여할 수 있다.
- Bash 명령어를 TypeScript/JavaScript 함수로 변환하여 실행하는 구조이며, `cat`, `cp`, `base64`, `jq`, `python3`, `sqlite`, `curl` 등 다양한 명령어와 파이프·리다이렉션·명령어 체이닝을 지원한다.
- 대용량 JSON 파일을 프롬프트에 직접 넣는 방식은 **13만 3,000 토큰**을 소비하지만, Just Bash를 활용하면 동일한 작업에 **6,000 토큰**만 사용해 약 95% 절감이 가능하다.
- 단순한 정보 검색뿐 아니라 범위 조건 필터링·데이터 조작 등 복잡한 쿼리에서 정확도가 크게 향상된다.
- AI SDK(`bash-tool` 패키지)와 연동하면 코드 몇 줄만으로 에이전트에 Bash 도구를 붙일 수 있으며, 화이트리스트 설정으로 보안도 관리 가능하다.

### 주요 내용

#### 1. 문제 제기 - 기존 방식의 한계
AI 에이전트에게 Bash 접근 권한을 주려면 실제 쉘, 파일 시스템, 서버, 컨테이너 등 복잡한 인프라가 필요했다. 또는 대용량 데이터를 다룰 때 파일 전체를 프롬프트에 삽입하는 단순한 방법을 쓰기도 하는데, 이는 토큰을 과도하게 소비하고 복잡한 데이터 조작 질문에서는 오답을 낼 가능성이 높다.

#### 2. Just Bash 소개 및 작동 원리
Just Bash는 Bash 명령어를 TypeScript로 구현한 패키지다. `exec()` 함수에 Bash 명령어를 전달하면 해당 명령이 JavaScript 함수로 변환되어 실행된다. 파일은 실제 디스크가 아닌 인메모리 가상 파일 시스템에 저장된다. 필요하다면 실제 파일 시스템을 연결하는 옵션도 제공된다. 반환값은 `stdout`, `stderr`, 종료 코드로 구성된 객체다.

#### 3. 지원 명령어 및 기능
- 기본 명령어: `cat`, `cp`, `base64`, `echo`, `head` 등
- 고급 데이터 처리: `jq`, `python3`, `sqlite`
- 네트워크: `curl` (화이트리스트로 보안 제어 가능)
- 쉘 기능: 파이프(`|`), 리다이렉션(`>`), 명령어 체이닝(`&&`) 지원

#### 4. 실전 비교 데모 - 토큰 절감 효과
대용량 JSON 파일에서 특정 레코드를 찾는 동일한 작업을 두 방법으로 비교했다.

| 방법 | 사용 토큰 |
|---|---|
| 파일 전체를 프롬프트에 삽입 | 133,000 토큰 |
| Just Bash 활용 (jq 명령 실행) | 6,000 토큰 |

에이전트는 `jq` 명령 실행 중 오류가 발생하자 `head` 명령으로 파일 구조를 먼저 확인한 뒤 올바른 쿼리를 재시도하는 자율적 문제 해결 능력도 보여줬다.

#### 5. AI SDK 연동 방법
AI SDK의 `bash-tool` 패키지를 사용해 채팅 API 엔드포인트에 새로운 Bash 도구를 생성하고, 시뮬레이션 환경에 전달할 파일과 저장 경로(`/workspace` 등)를 설정한다. 패키지가 제공하는 에이전트 지침(시스템 프롬프트)을 함께 전달하면 에이전트가 Bash 도구 사용법을 자동으로 이해한다.

### Q&A

**Q1. Just Bash는 실제 시스템에 영향을 줄 수 있는가? 보안 측면에서 안전한가?**
Just Bash는 실제 쉘이나 운영체제 파일 시스템에 연결되지 않으며, 모든 파일은 인메모리 가상 파일 시스템에서만 존재한다. 따라서 에이전트가 악의적인 명령을 실행하더라도 실제 서버나 호스트 환경에는 영향을 주지 않는다. 네트워크 요청(`curl`)은 화이트리스트를 통해 허용된 도메인만 접근하도록 제한할 수 있어 보안 관리가 가능하다. 단, 실제 파일 시스템 연결 옵션을 활성화할 경우 별도의 보안 검토가 필요하다.

**Q2. 어떤 Bash 명령어까지 지원되며, 지원되지 않는 명령어는 어떻게 처리되는가?**
`cat`, `cp`, `echo`, `head`, `base64` 등 기본 명령어부터 `jq`, `python3`, `sqlite` 같은 고급 데이터 처리 도구, 그리고 `curl`을 통한 네트워크 요청까지 폭넓게 지원된다. 파이프, 리다이렉션, 명령어 체이닝 등 쉘 기능도 지원된다. 지원되지 않는 명령어의 경우 오류 코드와 함께 반환되며, 영상에서 에이전트가 `jq` 오류 발생 시 `head`로 대체하는 것처럼 AI가 스스로 대안을 찾아 재시도할 수 있다.

**Q3. Just Bash를 사용할 때 기존 RAG(검색 증강 생성) 방식과 비교해 어떤 장단점이 있는가?**
Just Bash는 에이전트가 직접 파일에 접근해 필요한 데이터를 추출·조작하므로, RAG처럼 별도의 벡터 DB나 임베딩 파이프라인 구축이 필요 없어 초기 설정이 훨씬 간단하다. 복잡한 조건 필터링이나 집계 연산(예: 특정 범위 레코드 중 특정 조건 카운트)에서는 RAG보다 높은 정확도를 보인다. 다만 RAG는 의미론적 유사도 기반 검색에 강점이 있어 자연어 질의에 더 적합할 수 있으며, Just Bash는 구조화된 데이터(JSON, CSV, SQLite 등) 처리에 특히 효과적이다.
